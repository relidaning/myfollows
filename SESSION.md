## 2026-07-29 — YouTube cookie-import login, first real sync fixes, container port collision
Replaced the noVNC-driven YouTube login flow's embedded modal with a proper new-tab open, then (per user request to avoid VNC/remote-control entirely) built `scripts/import_youtube_cookies.py` to lift live session cookies from the user's local Chrome (decrypted via the Secret Service D-Bus keyring) into `data/youtube_storage_state.json`, plus a `/api/youtube/reload_session` endpoint so the running container picks up a re-imported session without a restart. Confirmed a full sync (90 videos, 33 creators, ~12.6s) working end-to-end afterward; README's "YouTube login" section now documents cookie-import as "Option B" alongside the VNC flow.
